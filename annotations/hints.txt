# Per-address hints for tools/gen.py.
#
#   data  START END KIND        bytes START..END-1 are data, not code
#                               KIND: long | short | byte | ascii | zero | offs16
#                               (offs16 = 16-bit offsets from cb to a label)
#   align START N               the nop run at START pads to a multiple of N
#   reg   START END rN NAME     call register N "NAME" within START..END-1
#   opnd  ADDR TEXT             replace the last operand of the instruction at ADDR
#
# All offsets are hexadecimal, relative to EmTop.
