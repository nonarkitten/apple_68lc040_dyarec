# What is This

This is a disassembly of the original Apple 68LC040 Dynamic Recompiler. It is provided for educational purposes only as a tool for developing new emulators using Apples rather unique method.

The details of this emualtor are in the patents (included) the last of which (US5790825) expired on November 8, 2015. 

The key document is US5790825 which explains in-depth how the Dynamica Recompiler worked with the other two documents providing background information as well as explanation depth.
